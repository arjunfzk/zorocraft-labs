# ZoroCraft Labs

AI-Native Apps & Automation Agency website. Built with vanilla HTML, CSS, and JavaScript.

## Features

- **URL-based personalization**: Visit `/firstname_companyname` or `/_companyname` for personalized greetings
- **Video showcases**: Auto-playing project demo videos with optimized loading
- **Mobile-first responsive design**
- **Analytics integration**: GTM, Clarity, PostHog

## Development

Just open `index.html` in a browser or use a local server.

## Deployment

Hosted on GitHub Pages with custom domain `zorocraftlabs.com`.
